# Library Server

Серверная часть приложения библиотеки из курса по асинхронному программированию. Приложение нужно для демонстрации нюансов работы с сетевыми запросами и закрепления материала на практике.

Клиентская часть находится в [отдельном репозитории](https://github.com/Kovarniy/async-java-script-module-0).

Для полноценной работы нужно запустить и клиентскую, и серверную часть.

## Требования

- Node.js (версия 18 или выше)
- Yarn

## Запуск

1. Установите зависимости: `yarn install`
2. Запустите сервер: `yarn start`
3. Документация API (Swagger UI) доступна по адресу: `http://localhost:3000/api#/`

Для корректной работы клиентского приложения должен быть запущен сервер.
